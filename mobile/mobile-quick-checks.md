# Mobile testing quick checks

Short list for a first pass on a phone.

- Rotate the screen: layout and entered data survive.
- Interrupt with a call or notification and return.
- Switch to another app and back after a few minutes.
- Turn on airplane mode mid-action: clear error, no crash.
- Slow network: loading states show, no double submit.
- Small and large screen sizes, large system font.
- Back button and gestures behave as expected.
- Permissions: deny, then allow later from settings.
- Keyboard covers no input or button.
- Install, update and uninstall keep or clear data as intended.

Reference checklist only. It does not claim any test was run.
