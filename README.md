# QA Portfolio - Abdul Moez

Practical manual QA work: test plans, test cases, bug reports, regression checklists, API testing notes, and a Claude prompt library for QA workflows.

Everything here is practice work against public demo applications (mainly saucedemo.com, the standard demo app built for QA practice). Artifacts follow the same structure I use in client work.

## Contents

| Folder | What it holds |
|---|---|
| test-plans/ | Test plans with scope, approach, entry/exit criteria |
| test-cases/ | Scripted test cases in table form (ID, preconditions, steps, expected, priority) |
| bug-reports/ | Bug reports with environment, repro steps, expected vs actual, severity |
| checklists/ | Regression and smoke checklists for web apps |
| api-testing/ | Postman-based API testing notes and examples |
| prompt-library/ | Reusable Claude/ChatGPT prompts for QA work |

## How I work

- Every bug report includes title, environment, preconditions, exact steps, expected result, actual result, severity/priority, and evidence notes.
- Test cases are written to be executed by anyone without extra explanation.
- AI tools help draft and expand coverage; every output is verified by hand before it ships.
