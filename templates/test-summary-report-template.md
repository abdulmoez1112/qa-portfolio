# Test summary report template

Use one page at the end of a test cycle.

## Header
- Project and build tested
- Dates and tester
- Environment (browser, OS, device)

## Scope
- What was tested
- What was not tested, and why

## Results
| Area | Planned | Run | Passed | Failed | Blocked |
|------|---------|-----|--------|--------|---------|
|      |         |     |        |        |         |

## Defects
- Count by severity
- Open critical or high bugs, with links

## Risks
- Untested areas
- Flaky or unclear behaviour

## Recommendation
Ship, ship with known issues, or hold, with one sentence of reasoning.

This is a blank template, not a record of a test run.
